# Código de conducta

Esta plantilla busca un espacio técnico, colaborativo y respetuoso para crear marketplaces de Claude Code y Codex.

Se espera comunicación clara, crítica sobre el trabajo y respeto por las personas. No se toleran acoso, discriminación, ataques personales, publicación de datos privados ni contribuciones deliberadamente maliciosas.

Para vulnerabilidades técnicas, utiliza `SECURITY.md` y un canal privado.
