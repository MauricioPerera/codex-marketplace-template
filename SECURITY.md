# Política de seguridad

Esta plantilla cubre manifests, plugins, skills, scripts, GitHub Actions y la GitHub Page generada. Revisa el código y las integraciones de cualquier plugin antes de instalarlo; nunca incluyas secretos, tokens o datos personales en issues o pull requests.

No publiques vulnerabilidades explotables en un issue público. Activa **Private vulnerability reporting** en tu copia del repositorio o contacta al mantenedor configurado en GitHub. Incluye archivo, versión, pasos de reproducción, impacto y evidencia sin datos sensibles.

Las validaciones automáticas no sustituyen una revisión humana. Los plugins no deben exfiltrar datos, leer secretos sin autorización ni ejecutar integraciones externas no documentadas.
